# Human-owned decisions and approvals

Phase 0 deliberately does not decide or activate the following.

## Repository administration

- Select or create the GitHub repository and configure the local `origin` remote.
- Confirm the permanent repository/module name if it differs from `github.com/KDTikkly/Cytisus`.
- Apply branch protection and confirm CODEOWNERS/reviewer groups.
- Approve dependency update policy and organization-level security settings.

## Legal, compliance, and partners

- Legal entity and U.S. licensed structure.
- Broker/clearing, sponsor bank, ACH/Wire provider, custodian, venues, card issuer/program manager, RWA issuer/SPV/custodian, KYC/AML/sanctions, chain analytics, tax forms, data retention, market-data licensing, and supported jurisdictions.
- Production fees, limits, risk thresholds, cooling policy, and all other configurable commercial or compliance values.

## Production operations

- Production credentials, KMS/Secrets Manager setup, network boundaries, environment approvals, provider activation, data migration, and deployment.
- Merge to `main`, release creation, and any staging or production deployment.

Local simulator fixtures are synthetic and do not imply that any provider, legal approval, fee schedule, or production capability exists.
